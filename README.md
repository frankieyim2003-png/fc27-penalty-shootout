# FC 27 Penalty Shootout

Static GitHub Pages game: FC 27 Penalty Shootout with PlayStyles+ and PeerJS Online 1v1.

Play: https://frankieyim2003-png.github.io/fc27-penalty-shootout/

## Online 1v1

Both players open that same site and need a network connection. One player taps ONLINE and shares the 6-character room code. The friend opens the same site, taps ONLINE, and enters the code.
