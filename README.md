# FC 27 Penalty Shootout

Static GitHub Pages game: FC 27 Penalty Shootout with PlayStyles+ and Online 1v1.

Play: https://frankieyim2003-png.github.io/fc27-penalty-shootout/

## Online 1v1

Both players open that same site on a phone or computer and need an internet connection. One player taps ONLINE and shares the 6-character room code. The friend opens the same site, taps ONLINE, and enters the code. They do not need to be on the same Wi-Fi.
